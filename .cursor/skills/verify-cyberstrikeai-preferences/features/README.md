# Web session and preferences

Run the helper from the parent skill on a fresh database and Chrome profile. It starts in en-US with system theme and a light OS preference. Read these entries in execution order. A missing control, failed HTTP action, or missing persisted value fails the run.

- [Session](session.md) covers signing in and signing out.
- [Theme](theme.md) covers the header and Settings → Appearance.
- [Language](language.md) covers both language selectors and Japanese after reload.

The helper signs out after the preference checks. The screenshot names in each entry are relative to the printed evidence directory.
