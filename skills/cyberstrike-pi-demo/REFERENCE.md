# API / Reference (Example)

## HTTP `/api/skills/{id}`

- `resource_path`: a relative path inside the package, for example `FORMS.md` or `scripts/payloads.txt`.
- `depth=summary`: summary and table of contents only, suited to a first retrieval pass.

## Multi-Agent Runtime

- Use the Pi **`skill`** tool to load skill packages progressively; optionally enable `multi_agent.skills.filesystem_tools` to access files inside the package.
