# 脆弱性レポートのダウンロード

[English](../en-US/word-reports.md) | [中文](../zh-CN/word-reports.md)

脆弱性管理の一覧で、各脆弱性の右側にあるダウンロードアイコンをクリックし、ダイアログで **Markdown（.md）** または **Word（.docx）** を選択します。選択すると、その 1 件の脆弱性がダウンロードされ、キャンセルまたは Esc を押した場合はダウンロードされません。ダウンロードに失敗した場合はダイアログが残るため、選び直すことができます。

Markdown は既存の内容、UI 言語、ファイル名をそのまま踏襲します。Word には、選択した脆弱性の基本情報、説明、前提条件、再現手順、証拠、影響、修正の推奨事項、再テスト記録が含まれます。元のステータスは保持され、未確認や誤検知のものが確認済みの脆弱性に書き換えられることはありません。証拠はプレーンテキストとしてエクスポートされ、その中の HTML や Markdown は解析されず、スクリーンショットも自動では埋め込まれません。

この機能は自動生成タスクの設定、データベース構造の変更、追加のレポート成果物の保存を行いません。サーバーに Office、Python、Pandoc をインストールする必要はありません。ただし、Word ファイルを閲覧するソフトウェアには中国語フォントが必要です。

Word のダウンロードには `GET /api/vulnerabilities/:id/download?format=docx` を使用し、`vulnerability:read` と対応する脆弱性のリソースアクセス範囲が必要で、追加のファイル管理権限は不要です。この API は `format=md` もサポートしており、フォーマットパラメーターが不正な場合は 400、存在しないレコードは 404、権限のないリクエストは 403 を返します。Word の本文は 8 MiB に制限されており、超過すると生成失敗が返されます。

従来のページ単位の Markdown 一括エクスポートは変更ありません。
