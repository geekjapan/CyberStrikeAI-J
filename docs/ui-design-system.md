# UI Style Conventions

The workbench uses React and Semi Design. Pages live in `web/frontend/src/pages/`. Shared table, drawer, toast and Markdown views live in `web/frontend/src/components/ui.jsx`. Global layout and theme styles are in `web/frontend/src/styles/app.css`.

Verify drawers, keyboard focus, table overflow and theme switching on desktop and mobile. For build and browser regression commands, see the [frontend development guide](../web/frontend/README.md).
